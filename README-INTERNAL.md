# Looped Clinic Asset Generator — Internal Dashboard

Open `looped-wl-tool.html` in Chrome.

## Standard workflow
1. Open **Clinic Dashboard**.
2. Enter the clinic name.
3. Upload the clinic logo once.
4. Review the generated App Logo, Header Mark, Hero Card, App Background, and Final App Mockup.
5. Download individual assets or use **Download All Assets ZIP**.

Use **Show Advanced Tools** only when an asset needs additional adjustment. The original Logo Resizer, Background, Hero Card, and Final Mockup editors remain included.

Transparent PNG, SVG, or WebP logos provide the best results. The dashboard intentionally does not include the unreliable automatic background-removal step.


## Recommended logo format
Use a transparent/alpha PNG whenever possible. Background removal remains available as a fallback, but it is not the recommended internal workflow.

## Advanced navigation
App Logo and Header are separate advanced tabs for clarity. The dedicated Hero Card tab is the only supported hero workflow.
