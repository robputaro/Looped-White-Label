# Vercel deployment

Deploy the contents of this folder as the Vercel project root.

- `index.html` is the production entry point.
- All large image assets are stored normally under `/assets/` instead of embedded in the HTML.
- No build command is required.
- Framework preset: **Other**.
- Output directory: leave blank.
- `looped-wl-tool.html` is retained only as a lightweight redirect for old bookmarks.

## GitHub
Commit the **contents of this folder at the repository root**. Do not upload the zip itself as the website source.
