Logo Resizer

Fit & pad logos to App, wide, or Hero canvas size. Transparency preserved, originals untouched.

Detects the background color from the top-left corner and clears every matching pixel in the image — including color-filled holes inside letters (e.g. the counters in "o," "a," "p"). Raise tolerance if faint edge pixels remain; lower it if it starts eating into the logo's own colors.

Trims away empty transparent margins around the logo before resizing, so the actual artwork fills more of the target canvas instead of shrinking to fit a square or differently-shaped source file. Most useful for wide/short canvases like 600×160. If "Remove solid background" is also on, cropping happens after the background is cleared.

If the logo has a solid colored background, the padding area will be flood-filled with that same color instead of left transparent — so it looks like the background was always the target size. Samples the background color from the logo's corner. Don't use alongside "Remove solid background."
